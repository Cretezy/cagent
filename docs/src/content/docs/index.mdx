## Why Cagent

<CardGrid stagger>
	<Card title="Work with guardrails" icon="lock">
		Review exact edits and permission requests before they run. Saved rules remain explicit,
		scoped, and editable. [Understand permissions](/permissions/)
	</Card>
	<Card title="Keep durable context" icon="document">
		Resume local conversations, revisit branches, fork from earlier messages, and compact long
		sessions without losing the transcript. [Manage conversations](/conversations/)
	</Card>
	<Card title="Shape the workflow" icon="setting">
		Choose providers, models, modes, agents, skills, instructions, MCP servers, keybindings, and
		the interface. [Configure Cagent](/configuration/)
	</Card>
	<Card title="Automate from the CLI" icon="terminal">
		Run one-off tasks, stream JSON events, restrict tools, and validate the final result against a
		JSON Schema. [Run headlessly](/headless/)
	</Card>
</CardGrid>
